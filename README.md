# 🐍 Python Basics – Input, Variables, Operators & Type Conversion

## 📌 Project Description

This project contains beginner-friendly Python programs designed to understand the fundamental concepts of Python programming.

The programs cover user input, variables, data types, type conversion, arithmetic operators, comparison operators, logical operators, assignment operators, and basic mathematical calculations.

## 📚 Programs Included

### 1. Display Personal Details
Takes the user's name, age, and height as input and displays them.

### 2. Personalized Greeting
Takes the user's name and displays a personalized greeting.

### 3. Add Two Numbers
Takes two numbers as input and adds them after converting them from strings to integers.

### 4. Float Input
Takes a decimal number using the `float()` function.

### 5. Sum Using Arithmetic Operator
Adds two numbers using the `+` operator.

### 6. Area of Rectangle
Calculates the area of a rectangle.

Formula:

Area = Length × Breadth

### 7. Quotient and Remainder
Calculates the quotient and remainder of two numbers.

### 8. Power Calculation
Calculates the power of a number using the `**` operator.

### 9. Average of Three Numbers
Calculates the average of three numbers.

### 10. Greater Than Comparison
Checks whether one number is greater than another.

### 11. Equality Check
Checks whether two numbers are equal.

### 12. Both Numbers Positive Check
Checks whether both numbers are positive.

### 13. At Least One Even Number
Checks whether at least one of two numbers is even.

### 14. Logical NOT
Demonstrates the use of the `not` operator.

### 15. Augmented Assignment Operations
Demonstrates updating a variable using arithmetic operations.

### 16. Exchange Values of Two Variables
Demonstrates different methods of swapping two variables.

### 17. Simple Interest
Calculates simple interest.

Formula:

SI = (Principal × Rate × Time) / 100

### 18. Temperature Conversion
Converts Celsius temperature into Fahrenheit.

Formula:

F = (C × 9 / 5) + 32

### 19. Divisibility by 3 and 5
Checks whether a number is divisible by both 3 and 5.

### 20. Sum of Digits of a Two-Digit Number
Calculates the sum of the digits of a two-digit number.
