# Python Basics – Input, Variables & Type Conversion

## Project Description

This project contains simple Python programs for beginners.

These programs demonstrate:
- Variables
- User input
- Output
- Arithmetic operations
- Type conversion

## Programs Included

### 1. Display Personal Details

This program takes the user's name, age, and height and displays them.

### 2. Personalized Greeting

This program asks for the user's name and displays a personalized greeting.

### 3. Add Two Numbers

This program takes two numbers as input and adds them.

### 4. Float Input

This program takes a decimal number as input using the float data type.

## Concepts Used

- Variables
- input()
- print()
- int()
- float()
- Addition
- f-strings
- Type conversion

## Requirements

- Python 3.x
- VS Code or any Python editor

## Learning Objective

The goal of this project is to learn the basics of Python input, variables, data types, output, and type conversion.
